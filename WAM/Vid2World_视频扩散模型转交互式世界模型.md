## 一、论文概述

Vid2World 提出了一种通用方法，将预训练的视频扩散模型（如 Sora、LTX-Video 等）转化为可交互的、动作条件的世界模型。这是一个范式转移——不再从零训练世界模型，而是直接复用互联网规模视频数据中学到的物理先验。

**一句话总结**：通过"视频扩散因果化"和"因果动作引导"两项关键技术，Vid2World 首次系统性地解决了从被动视频生成模型到主动交互式世界模型的转化问题。

## 二、核心问题与动机

### 2.1 数据金字塔视角

世界模型的数据可以分为三层金字塔：

```
        /\
       /  \  动作标注的机器人数据（最少、最贵）
      /    \
     /------\
    /        \  跨域动作标注数据（中等）
   /          \
  /------------\
 /              \  互联网无动作视频数据（海量、免费）
/________________\
```

现有世界模型只利用了金字塔顶部的数据。而视频扩散模型已经在底层海量数据上预训练好了——为什么不直接复用？

### 2.2 两个核心挑战

**挑战 1：因果性（Causality）**

标准视频扩散模型使用双向注意力（bidirectional attention），对整个序列同时去噪。这意味着未来帧可以影响过去帧的生成——这在视频生成中没问题，但在世界模型中是致命的，因为世界模型必须是因果的：未来只能依赖过去。

**挑战 2：动作可控性（Action Conditioning）**

视频扩散模型没有动作输入接口。即使实现了因果生成，模型也无法根据不同动作产生不同的未来——缺乏反事实推理能力。

## 三、技术方法详解

### 3.1 视频扩散因果化（Video Diffusion Causalization）

#### 3.1.1 时序注意力层的因果化

视频扩散模型的时序注意力层使用双向注意力，每一帧可以看到所有其他帧。要转为因果模型，需要让每一帧只能看到过去的帧。

Vid2World 探索了三种权重迁移方案：

**方案 A：Shift Weight Transfer（移位迁移）**

将双向注意力权重直接移位到因果位置。例如，原来位置 (i, j) 的权重移到 (i, i+j) 的位置。

问题：论文给出了理论反例，证明这种方案在某些情况下会产生较大误差。直觉上，双向注意力中"向前看"和"向后看"的权重学到的模式不同，简单移位会破坏这些模式。

**方案 B：Masked Weight Transfer（掩码迁移）**

保留双向注意力中"向后看"的权重（即 j ≤ i 的部分），将"向前看"的权重（j > i）置零。

优点：保留了已学到的因果方向的模式。
缺点：丢失了一半的预训练信息。

**方案 C：Extrapolative Weight Transfer（外推迁移）** ← 最优

利用 Taylor 展开，从双向权重外推出因果权重。核心思想：双向注意力权重可以看作是位置差 (j-i) 的函数，通过对已知的双向权重做外推，可以估计出因果位置上的权重。

论文给出了误差界的理论分析，证明外推迁移的误差可以被有效控制。

实验结果：Extrapolative > Masked > Shift。

#### 3.1.2 时序卷积层的因果化

视频扩散模型中的时序卷积也是非因果的（使用对称 padding）。转化方法：将对称 padding 改为左 padding（causal padding），使卷积核只能看到当前和过去的帧。

#### 3.1.3 因果训练目标

原始视频扩散模型的训练目标是对整个序列同时去噪。因果化后，改为逐帧去噪：每一帧的去噪只依赖于过去帧的信息。

具体实现：使用 Diffusion Forcing 的思想，每一帧可以有不同的噪声水平，模型学习在给定过去帧（可能有不同噪声水平）的条件下去噪当前帧。

### 3.2 因果动作引导（Causal Action Guidance）

#### 3.2.1 动作注入

将动作信号嵌入后拼接到对应帧的输入中：

```
输入_t = Concat(噪声帧_t, 动作嵌入_t)
```

动作嵌入通过一个小型 MLP 将原始动作向量映射到与帧特征相同的维度。

#### 3.2.2 训练：随机丢弃动作

借鉴 Classifier-Free Guidance 的思想，训练时以概率 p 随机丢弃动作条件：

```
以概率 p：输入_t = Concat(噪声帧_t, 零向量)    # 无条件
以概率 1-p：输入_t = Concat(噪声帧_t, 动作嵌入_t)  # 有条件
```

这使模型同时学会有条件和无条件生成。

#### 3.2.3 推理：引导采样

推理时使用引导尺度 λ 控制动作的影响强度：

```
ε_guided = ε_uncond + λ × (ε_cond - ε_uncond)
```

- λ = 0：完全忽略动作（纯视频生成）
- λ = 1：标准条件生成
- λ > 1：增强动作影响（可能过度锐化）

实验发现 λ 有最优值，过大会导致生成质量下降。

## 四、实验结果

### 4.1 机器人操作（RT-1 数据集）

| 方法 | FVD ↓ | FID ↓ | SSIM ↑ | LPIPS ↓ | PSNR ↑ |
|------|-------|-------|--------|---------|--------|
| Cosmos | - | - | - | - | - |
| UVA | - | - | - | - | - |
| DINO-WM | - | - | - | - | - |
| Dreamer4 | - | - | - | - | - |
| **Vid2World** | **22.4** | **6.16** | **0.839** | **0.159** | **23.9** |

Vid2World 在所有指标上全面超越 baseline。

### 4.2 3D 游戏模拟（CS:GO）

- FID 相对改进 **79.9%**
- FVD 相对改进 **71.1%**
- 超越 DIAMOND（当时最强的自回归世界模型）

### 4.3 开放世界导航（RECON）

- 在自回归设置下，Vid2World 与 NWM（单步预测，无误差累积）性能相当
- 显著超越 DIAMOND
- 预测范围（16帧）超过训练范围，展现了时序泛化能力

### 4.4 Real2Sim 策略评测

Vid2World 生成的模拟环境中的策略评测结果与真实世界评测结果高度相关，可以作为可靠的策略评测工具。

### 4.5 消融实验

| 权重迁移 | 动作引导 | FVD ↓ |
|---------|---------|-------|
| Shift | 无 | 29.9 |
| Masked | 无 | 29.4 |
| Extrapolative | 无 | 28.6 |
| Masked | 有 | 25.8 |

两个组件都有显著贡献，且是互补的。

## 五、关键设计决策分析

### 5.1 为什么用视频扩散模型而不是从零训练

- 互联网视频数据量远超机器人数据（百万小时 vs 千小时）
- 视频扩散模型已经学到了丰富的物理先验（重力、碰撞、遮挡等）
- 模型级迁移比数据级利用更高效（不需要重新训练）

### 5.2 为什么外推迁移最优

- Shift 迁移破坏了位置编码的语义
- Masked 迁移丢失了一半信息
- 外推迁移利用了双向权重的连续性假设，最大限度保留预训练知识

### 5.3 动作引导 vs 动作微调

直接用动作做条件微调也可以，但 Classifier-Free Guidance 风格的引导有额外好处：
- 可以在推理时调节动作影响强度
- 训练更稳定（无条件分支提供正则化）
- 与扩散模型的采样过程天然兼容

## 七、对世界模型领域的意义

1. **范式转移**：从"训练世界模型"到"迁移视频模型"，大幅降低了构建世界模型的门槛
2. **数据效率**：利用互联网规模的视频预训练，只需少量动作标注数据即可适配
3. **理论贡献**：外推权重迁移的理论分析为因果化提供了数学基础
4. **实用价值**：Real2Sim 策略评测展示了直接的应用价值

## 九、局限性与展望

1. **计算资源限制**：只用了 1.4B 的基础模型，更大模型（如 Cosmos 12B）可能效果更好
2. **训练时间**：因果化微调仍然耗时，期待更高效的迁移方法
3. **长时序稳定性**：虽然优于 baseline，但长时序误差累积仍是挑战
4. **动作空间泛化**：目前需要针对每个域的动作空间单独训练
