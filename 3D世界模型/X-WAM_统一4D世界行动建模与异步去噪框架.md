## 一、研究动机与问题定义

### 1.1 现有范式的局限

当前具身AI基础模型主要分为两大范式：

| 范式 | 代表方法 | 优势 | 局限 |
|------|----------|------|------|
| **策略模型（VLA）** | RT-2, OpenVLA, π₀, π₀.5 | 指令跟随、语义推理 | 缺乏几何直觉和物理感知 |
| **世界模型** | Genie, DreamerV3, IRASim | 模拟未来观测、物理动力学 | 不直接产生可执行动作 |
| **统一世界行动模型（WAM）** | UWM, Motus, VideoVLA, DreamZero | 联合建模视频和动作 | 仅限2D像素空间，缺乏3D感知 |

### 1.2 X-WAM要解决的两个核心问题

1. **空间感知缺失**：现有统一模型仅在2D像素空间建模，缺乏显式三维几何感知，导致物理上不合理的未来预测和无法进行几何忠实的3D重建
2. **效率-质量矛盾**：高维视频生成需要大量去噪步骤，而低维动作仅需少量步骤，如何在统一框架中平衡两者的效率和质量

### 1.3 X-WAM的四重目标

在单一架构中同时实现：
- 高保真视频生成
- 3D空间重建
- 高策略成功率
- 高效动作执行

## 二、整体架构设计

### 2.1 模型输入输出

**输入：**
- 语言指令 c
- 初始本体感受状态 s₀
- 多视角初始RGB观测 O₀

**输出：**
- 未来RGB视频 O₁:H（H=8帧）
- 未来深度视频 D₁:H（H=8帧）
- 未来本体感受状态 s₁:H（H=8）
- 未来动作 a₁:K（K=32）

**关键设计**：动作预测频率是视频帧率的4倍（K/H=4），反映了动作需要更高控制频率的需求。

### 2.2 基础骨干网络

基于预训练视频生成扩散Transformer——**Wan2.2-TI2V-5B**进行微调。

**编码方式：**
- RGB视频：通过原始Causal VAE编码器 → z_O = E(O)
- 本体感受状态：通过可学习MLP → z_s = MLP_s(s)
- 机器人动作：通过可学习MLP → z_a = MLP_a(a)

**统一去噪序列：**
```
Z = [z_O₀, z_O₁:H, z_s₀, z_s₁:H, z_a₁:K]
```

使用双向全注意力（bidirectional full attention）处理整个序列。初始观测z_O₀和初始状态z_s₀在去噪过程中保持固定（噪声时间步t=0）。

### 2.3 多视角兼容设计

原始视频扩散模型使用3D RoPE（Rotary Position Embeddings）编码时间和空间位置。为支持多视角而不破坏预训练位置编码：
- 为每个视角的token添加**可学习视角嵌入（learnable view embeddings）**
- 状态和动作使用与视频token相同的时间维度RoPE

### 2.4 相机位姿处理

机器人操作中的相机分为两类：
- **静态相机**（第一人称/第三人称）：位姿在任务执行中保持不变
- **动态相机**（腕部安装）：通过固定的手眼标定矩阵与末端执行器刚性连接

X-WAM预测末端执行器位姿 T_ee ∈ SE(3)，通过固定手眼标定矩阵推导腕部相机位姿：
```
T_wrist = T_ee · T_h2e
```

## 三、核心技术创新

### 3.1 轻量级深度自适应模块（Lightweight Depth Adaptation）

#### 问题背景

将深度信息引入统一模型的朴素方法：
- **序列拼接**：将深度图作为额外视频帧/通道拼接 → 序列长度翻倍，计算开销巨大
- **通道拼接**：沿通道维度融合RGB和深度 → token分布偏离预训练流形，学习困难

#### X-WAM的解决方案

**核心思想**：复制预训练DiT的最后M个block，构建专用深度预测分支。

**具体流程：**

给定N个DiT block的模型：

1. **共享主干**（前N-M个block）：处理统一序列Z，产生隐藏状态H
2. **分支初始化**：深度分支和主分支均从H初始化
   - Z_D^(0) = Z_m^(0) = H
3. **交错执行**（后M个block）：
   ```
   Z_D^(j) = DepthBlock_j(Z_D^(j-1) | Z_m^(j-1))   # 深度分支通过交叉注意力读取主分支
   Z_m^(j) = DiTBlock_{N-M+j}(Z_m^(j-1))            # 主分支独立运行
   ```

#### 单向注意力（Unilateral Attention）

- 深度分支**可以读取**主分支的输入（通过cross-attention）
- 主分支**不受**深度token影响
- 严格保持预训练权重的完整性

#### 深度监督

- 使用MSE损失回归当前视频帧的逆深度（inverse depth）
- 与Depth Anything 3等深度估计模型保持一致

#### 推理灵活性

深度分支在推理时**不需要参与每个去噪步骤**，可灵活开关，大幅减少rollout开销。

#### 实验验证

| 深度架构 | 成功率(%) | 延迟(ms) | PSNR↑ | CD↓ |
|----------|-----------|----------|-------|------|
| 无深度 | 63.0 | 1033 | 23.09 | – |
| 序列拼接 | 68.7 | **1888** | **23.60** | **0.0037** |
| 通道拼接 | 64.2 | 1266 | 23.20 | 0.0052 |
| **交错分支（X-WAM）** | **67.8** | **1033** | 23.46 | 0.0049 |

关键发现：
- 移除深度监督导致策略成功率从67.8%降至63.0%（-4.8%），证明显式空间建模对操作至关重要
- 交错分支在不增加延迟的情况下实现了接近序列拼接的质量

### 3.2 异步噪声采样（Asynchronous Noise Sampling, ANS）

#### 问题背景

视频和动作的去噪需求根本不同：
- **低维动作**：少量去噪步骤即可准确恢复
- **高分辨率视频**：需要更多步骤和精心设计的调度器

现有方法的问题：
- **同步去噪**：两种模态共享相同时间步 → 无法平衡推理速度和生成质量
- **完全解耦采样**：独立随机采样两种模态的噪声时间步 → 训练中出现t_O < t_a的配置（视频噪声低但动作噪声高），这在推理时永远不会出现 → 训练效率低下

#### ANS推理过程

为视频和动作分配不同的去噪步数：
- 动作/状态：T_a步（少量，如5-10步）
- 视频：T_O步（完整，如25-50步），T_a < T_O

**两阶段推理：**

1. **联合去噪阶段**（前T_a步）：视频和动作同时去噪，步长分别为1/T_O和1/T_a
2. **视频独立去噪阶段**（后T_O - T_a步）：动作已完全去噪并可立即执行，视频继续去噪（此时自然变为动作条件世界模型）

#### ANS训练过程——耦合联合采样

不同于独立采样，ANS从联合分布中进行耦合采样：

```
(t_O, t_a) ~ {
    t_a = 0, t_O ~ U(0,1)                                    概率 p
    t_a ~ U(0,1), t_O = t_a + (1-t_a)·b, b ~ Beta(1.5,1)    概率 1-p
}
```

**设计要点：**
- **第一种情况**（概率p）：动作条件视频生成，动作无噪声
- **第二种情况**（概率1-p）：异步联合生成
  - Beta(1.5, 1)分布重缩放到[t_a, 1]，使t_O偏向更高噪声水平
  - **关键约束**：始终保证 t_O ≥ t_a（视频噪声不低于动作噪声）
  - t_O条件于t_a采样，两者是**依赖**而非独立随机变量

#### 为什么耦合采样优于解耦采样？

| 采样策略 | 问题 |
|----------|------|
| 解耦采样 | 会产生t_O < t_a的训练样本（推理时不存在），浪费训练计算 |
| 耦合采样 | 严格匹配推理时分布，每个训练样本都对应有效的推理配置 |

#### ANS消融实验

| 噪声调度策略 | 成功率(%) | 延迟(ms) | PSNR↑ | AbsRel↓ |
|-------------|-----------|----------|-------|---------|
| 同步训练+同步推理 | 66.4 | **4665** | 23.48 | 0.0375 |
| 解耦训练+同步推理 | 66.3 | **4665** | 23.17 | 0.0397 |
| 解耦训练+异步推理 | 67.2 | 1033 | 22.60 | 0.0430 |
| **ANS训练+异步推理** | **67.8** | **1033** | **23.46** | **0.0349** |

关键发现：
- 异步推理实现**4.5倍加速**（4665ms → 1033ms）
- 解耦训练+异步推理导致重建质量显著下降（PSNR 22.60）
- ANS在相同延迟下实现最高成功率和最佳深度指标

## 四、训练细节

### 4.1 训练框架

基于Flow Matching框架微调。模型f_θ预测速度场 v = ε - z⁰：

**各模态速度预测损失：**
```
L_m = ||f_θ^m(z_m^{t_m}, t_m) - (ε_m - z_m^0)||²
```

**深度分支损失：**
```
L_depth = ||D̂ - D*||²  （逆深度MSE回归）
```

**总训练目标：**
```
L_total = L_O + λ_s·L_s + λ_a·L_a + λ_D·L_depth
```

其中 λ_s = λ_a = λ_D = 1.0

### 4.2 状态与动作表示

**统一接口设计**（兼容单臂和双臂机器人）：
- **状态**：16维绝对向量 = (位置3 + 四元数4 + 夹爪1) × 2臂
- **动作**：14维相对向量 = (Δ位置3 + Δ轴角3 + 夹爪动作1) × 2臂
- 单臂机器人：仅监督前8维状态和前7维动作
- 动作归一化：仅缩放不加偏置，保持零动作=无运动的语义

### 4.3 预训练数据

总计超过**5,800小时**，约**149万episodes**：

| 数据集 | 来源 | Episodes | 时长(h) |
|--------|------|----------|---------|
| AgibotWorld-Beta | 真实 | 866,562 | 2,221.5 |
| DROID | 真实 | 74,734 | 280.3 |
| InternA1-Aloha | 仿真 | 184,803 | 1,337.3 |
| InternA1-Genie1 | 仿真 | 50,638 | 174.0 |
| InternA1-Lift2 | 仿真 | 231,018 | 1,464.7 |
| RoboCasa MimicGen | 仿真 | 56,771 | 282.4 |
| RoboTwin 2.0 | 仿真 | 27,500 | 113.7 |

**数据预处理：**
- 移除包含底盘运动、灵巧操作和失败执行的episodes
- 过滤DROID中的静止帧
- 统一下采样至3.75 FPS，分辨率320×256
- 使用Video Depth Anything提取深度图（大部分预训练数据缺乏深度标注）

### 4.4 训练配置

**大规模预训练：**
- 256× NVIDIA H20 GPU
- 每GPU batch size 8（总batch 2048）
- AdamW优化器，峰值学习率 1×10⁻⁴
- 1000步线性warmup + 余弦衰减
- 训练40,000步
- 深度分支复制block数 M=10
- ANS动作条件概率 p=0.5

**基准微调：**
- 32× NVIDIA H20 GPU
- 每GPU batch size 4（总batch 128）
- 学习率 3×10⁻⁵
- 训练20,000步

### 4.5 推理配置

- 动作去噪步数 T_a = 10
- 视频去噪步数 T_O = 50
- 调度器：UniPC多步调度器
- Classifier-free guidance scale = 1.0
- 单次推理延迟约300ms/动作块（8步去噪）

## 六、技术洞察与设计哲学

### 6.1 为什么深度监督能提升策略成功率？

深度监督不仅用于3D重建，更重要的是增强了模型的**空间结构感知能力**。实验表明移除深度监督后成功率下降4.8%，说明显式空间建模为策略学习提供了有益的归纳偏置。

### 6.2 ANS的核心洞察

WAM不需要完全去噪视频就能解码准确动作——即使上下文包含高噪声视频token，模型仍能解码准确动作。ANS将这一观察形式化为系统的训练-推理对齐策略。

### 6.3 轻量级设计的权衡

交错深度分支是序列拼接和无深度之间的最优折中：
- 不增加序列长度（避免二次注意力复杂度爆炸）
- 不破坏预训练权重（单向注意力保证主分支不受影响）
- 推理时可灵活关闭（仅在需要3D重建时启用）

## 七、与相关工作的对比定位

### 7.1 与UWM的关系

UWM是统一世界行动建模的先驱工作，但仅在2D像素空间建模。X-WAM在UWM基础上引入显式3D空间感知，将统一模型从"2D像素预测器"提升为"空间感知的4D动力学模拟器"。

### 7.2 与DreamZero的关系

DreamZero利用因果注意力掩码和KV缓存减少推理延迟，但缺乏3D建模能力。X-WAM通过ANS实现类似的推理加速，同时额外提供4D重建能力。

### 7.3 与Motus的关系

Motus是统一潜在动作世界模型，在RoboTwin 2.0上表现优异。X-WAM在其基础上进一步引入空间感知，在Randomized设置下提升3.7%（87.0% → 90.7%）。

### 7.4 与3D-VLA/SpatialVLA等的关系

这些工作在VLA框架中引入3D信息，但不具备视频生成和世界建模能力。X-WAM是首个在统一世界行动建模范式中引入显式空间信息的工作。

## 八、局限性与未来方向

### 8.1 当前局限

1. **固定长度上下文窗口**：不支持历史信息或自回归rollout，在长时间操作中可能无法充分理解任务进度
2. **推理延迟**：相比专用策略模型仍有差距（约300ms/动作块 vs 专用VLA的更低延迟）

### 8.2 未来方向

- 历史条件化、KV缓存、自回归推理 → 支持更长时间范围
- 模型蒸馏、一致性模型、更激进的异步调度 → 进一步缩小延迟差距
- 架构和噪声调度策略与长上下文机制正交，可直接扩展

## 十、对世界模型领域的启示

1. **显式空间建模是必要的**：即使在2D视频预训练的基础上，引入3D监督也能显著提升策略性能，证明空间感知不仅是重建需求，更是操作能力的基础
2. **训练-推理对齐至关重要**：ANS的成功表明，简单的解耦采样会导致训练浪费，精心设计的联合分布能同时提升效率和质量
3. **统一建模的规模效应**：5800小时预训练数据 + 统一框架 = 多任务协同增益，单一模型在所有维度超越专用模型
4. **轻量级适配优于暴力扩展**：交错分支设计表明，保持预训练权重完整性的轻量适配比直接扩展序列更有效
